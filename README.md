# La Dolce Brew (Bangalore) — Website

## Run
- Open `index.html` in your browser (double-click).

## Customize
- **Cafe name / text**: edit `index.html`
- **Colors / styling**: edit `styles.css`
- **WhatsApp number** (for reservations): edit `WHATSAPP_NUMBER_E164` in `script.js`

## Notes
- The reservation form is **front-end only** (no server). It opens WhatsApp with a pre-filled message.
- The gallery uses nice **placeholder cards** (swap with real images later).
